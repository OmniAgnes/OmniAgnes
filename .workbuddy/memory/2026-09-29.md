## 修复：聊天区与侧边栏无法上下滚动

- **根因**：两处都用 Radix `ScrollArea`，其 Viewport 是 `size-full`，在 flex 容器（`flex-1` 但父级无确定高度链）里撑不开，内容溢出而不产生滚动。与之前 SettingsDialog 滚动失效同根因。
- **修法**：一律改原生滚动容器 `className="omni-scroll min-h-0 flex-1 overflow-y-auto"`，并把 `Chat.tsx` / `Sidebar.tsx` / `App.tsx` 的 flex 高度链补全（`h-screen` → `flex-col` → `flex-1 min-h-0` → 两侧 `h-full min-h-0` → 滚动区 `min-h-0 flex-1`）。**`min-h-0` 是关键，缺了它 flex 子项会被内容撑破不收缩。**
- 删除已无人引用的 `components/ui/scroll-area.tsx`（JS 体积 755→742 kB）。
- `index.css` 新增 `.omni-scroll`：细滚动条 + 悬停/聚焦才显形（Chromium 与 Firefox 双端），`overscroll-behavior: contain` 防滚动穿透。
- 聊天区顺带改进：原 `bottomRef.scrollIntoView` 会在流式输出时把用户强行拽到底部；改为 `stickRef` 记录「距底 < 80px 才跟随」，用户手动上滚后不再打扰，回到底部自动恢复跟随。
