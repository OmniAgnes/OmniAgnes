# 内置浏览器操作

通过 omni 自带的 `browser` 工具驱动 **桌面版内置浏览器**（Electron 壳中的真实 Chromium 视图）。
用户能在界面上直接看到你点的每一个位置——面板会自动展开，所见即所得。

> ⚠️ **仅桌面版可用。** 网页版（浏览器打开的 web UI）没有 Electron 壳，`browser` 工具会直接报错。
> 遇到该报错时不要重试、不要尝试安装任何东西，改用 `read` / `bash` 等工具，或告知用户请在桌面版中操作。

## 何时使用

- 需要**交互**：点击按钮、填写表单、登录后操作、翻页、展开折叠面板。
- 需要**登录态**：用户已登录的页面（内置浏览器复用桌面壳的会话）。
- 需要 **JS 渲染**或**反爬**页面：直接 HTTP 抓取拿到的是空壳页面。
- **不需要**浏览器的场景：公开页面、API、文档 → 直接 `curl` / `read`，别开浏览器。

## 核心工作流

```
open {url}  →  extract（看元素 + 坐标）  →  click / type  →  extract（验证结果）
```

**关键点：你必须先 `extract` 才能点击。** `click` 用的是视口绝对坐标，凭空猜坐标必然点错。

### 1. 打开页面

```json
{"op": "open", "url": "https://example.com/page"}
```

`open` 会等页面加载完成。后续在同一页面继续操作用 `navigate`（同标签页跳转），不要反复 `open` 新标签。
已经打开过、只是回退/前进 → `back` / `forward` / `reload`。

### 2. 提取页面结构（最重要的一步）

```json
{"op": "extract"}
```

返回内容包含：

- 标题、所有可见交互元素（链接/按钮/输入框等）**及其视口中心坐标** —— 坐标就是给 `click` 用的；
- 各级标题（h1/h2/h3）；
- 正文文本（截断到约 4000 字符）。

### 3. 交互

```json
{"op": "click", "x": 412, "y": 268}
{"op": "click", "x": 412, "y": 268, "doubleClick": true}
{"op": "type", "text": "hello@example.com"}
{"op": "key", "key": "Enter"}
{"op": "scroll", "x": 600, "y": 400, "amount": 600}
```

- `type` 向**当前焦点**元素输入，先 `click` 输入框获取焦点再 `type`；
- `key` 支持 `Enter` / `Tab` / `Escape` / `Backspace` / `ArrowDown` / `ArrowUp` 等；
- `scroll` 的 `amount` 为像素，**负值向上**；
- 页面在跳转/加载后，用 `wait {ms}` 稍等（例如 `{"op":"wait","ms":800}`）再 `extract`。

### 4. 其他

```json
{"op": "eval", "code": "document.querySelectorAll('a').length"}
{"op": "state"}   // 当前 url / 标题 / 加载状态
{"op": "show"}    // 展开面板（AI 动手时会自动展开，一般不用管）
{"op": "hide"}
{"op": "close"}   // 关闭内置浏览器
```

`eval` 用于 `extract` 够不到的场景（如读取某个隐藏输入框的值、滚动到某个元素）。
**优先用 `extract`**，它是"看页面"的正规方式。

## 排错

| 现象 | 原因 / 处理 |
|---|---|
| `内置浏览器不可用：当前不是桌面版` | 当前是网页版，桌面壳不存在。**不要重试、不要装 CLI**，改用其他工具。 |
| `click` 点了没反应 | 坐标过时了。重新 `extract` 拿最新坐标；若页面已滚动，先 `extract` 再点。 |
| `extract` 返回空元素 | 页面还没渲染完 → `wait` 后重试；或需要登录 → 提示用户手动登录。 |
| 操作卡住不动 | 页面可能弹了原生弹窗（alert/confirm）阻塞 JS，先 `eval` 检查或让用户处理。 |

## 不要做的事

- ❌ 不要 `bash` 里调 `browser-use` / `npx playwright` / 装任何浏览器驱动 —— 内置浏览器已够用，外部 CLI 本机并不存在。
- ❌ 不要凭记忆猜坐标或凭空描述页面内容 —— 一切以 `extract` 的返回为准。
- ❌ 不要在一个任务里反复 `open` 同一站点多个标签，保持单标签复用。
- ❌ 不要在用户明确要求"不要动我的界面"时展开面板。
